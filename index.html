About the Application

Crime rate prediction can help law enforcement agencies understand crime patterns, anticipate future trends, and plan resources to improve public safety. The dataset for this project is based on crime statistics for 19 Indian metropolitan cities from 2014 to 2021, covering ten categories of crime. The project uses a Random Forest Regression model to estimate crime rates based on city, crime type, and year.
